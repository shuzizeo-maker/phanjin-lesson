# 范進命運棋 ──〈范進中舉〉單人學習遊戲

高中國文〈范進中舉〉（《儒林外史》第三回節選，**課文依龍騰版國文第七課**）的學習遊戲。**單人遊玩**：學生一人對上 1–3 位取材自課文人物的電腦對手，沿著課文時間軸走棋：答題、抽卡、應考、看胡屠戶的臉色，最後依「聲望」放榜。以「普通」以上難度拿下第一名，可以領取證書。

- **預設 3D 棋盤**（three.js），**跑不動會自動改用 2D**；右上角按鈕可隨時切換 3D／2D，進度不會遺失。
- 單一 `index.html`，不需要安裝、不需要編譯，丟上 GitHub Pages 就能玩。
- 內建 40 題原創題目（讀音、釋義依龍騰版注釋），答完都有解析；教師可匯入／匯出、編輯題庫（JSON 或 Excel）。

---

## 一、怎麼玩

1. 按「開始應考」，輸入**姓名**（必填，證書會用到），**班級、座號**（選填），再選：
   - **電腦對手人數**：1–3 位；
   - **難度**：簡單（電腦約 50% 答對）／普通（約 65%）／困難（約 80%）；
   - **回合數**（8／10／12 輪或不限）、**時間上限**（不計時／10／15／20 分或自訂）、答題限時、棋盤畫面（自動／3D／2D）。
   回合數與時間上限，先到者為準。
2. 輪到你時按「🎲 擲骰子」（電腦也可按空白鍵）。電腦對手的回合會自動進行：先「思考」一下再擲骰、答題、抽卡；結果框會倒數幾秒後自動繼續，想快一點可直接按「繼續」。
3. 停在格子上會觸發事件：

| 格子 | 說明 |
| --- | --- |
| 問（問答） | 答一題，答對加體面或人情。 |
| 考（童試、鄉試） | **路過或停下都要應考**。童生在「童試」答對 → 秀才；秀才在「鄉試」答對 → 舉人。 |
| 屠（胡屠戶） | 先答題，再看胡屠戶的臉色：被罵「現世寶」，還是被捧成「賢婿老爺」。 |
| 事（情節） | 課文情節：進學回家、家中斷糧、抱雞賣集、報錄捷報、喜極而瘋…… |
| 命（命運卡） | 個人遭遇與科舉知識（號舍、亞元、黃甲、託病辭薦……），共 16 張，其中 4 張為追分卡。 |
| 世（世態卡） | 人情冷暖、前倨後恭；部分卡片要做抉擇（雪中送炭或錦上添花？），共 17 張，其中 5 張為追分卡。 |
| 起（應考半生） | 每經過一次，人情 +1。 |

4. **胡屠戶的臉色**依每位考生的功名與體面變化，從「鄙夷」「嫌棄」「說教」「客氣」到「奉承」，直接呈現課文的「前倨後恭」。
5. 答題時可以「請教同案」：花 1 點人情，刪去一個錯誤選項（電腦對手不使用提示）。
6. **公平機制（追分）**：聲望比全體平均低 3 分以上的考生（你或電腦都適用）會顯示「🔥 追分中」──
   - 答對題目額外 **體面 +1**；
   - 在考場（童試、鄉試）答錯，可以 **補考一次**；
   - 胡屠戶的奉承 **越聽越不稀罕**（加成遞減），目前領先者的奉承加成最多 +1；
   - 另有 9 張 **追分卡**（命運 4、世態 5）專門照顧落後的考生。
7. **沒有人會破產出局**。回合數或時間到（或按 🏁 提前放榜）就結算：
   **聲望 ＝ 體面 ＋ 人情 ＋ 功名加分（秀才 +5、舉人 +10）**；同分比答對題數。
   結算頁會顯示排名（解元、亞元……）、趣味獎項，以及 3 題「課後省思」供課堂討論。

> 「鄉紳來訪」格標示為「延伸」，取材自原著第三回課文節選以後的情節（張鄉紳登門），龍騰版課文並未收錄。

### 電腦對手

| 對手 | 取材 | 個性（抉擇卡怎麼選） |
| --- | --- | --- |
| 魏好古 | 范進的同案秀才 | 重情義，多半選「雪中送炭」 |
| 集上高鄰 | 飛奔到集上報喜的鄰居 | 愛湊熱鬧，多半「錦上添花」 |
| 跳駝子郎中 | 廟門口的外科郎中 | 精打細算，選對自己最划算的 |

難度只影響電腦的答對率（簡單 50%、普通 65%、困難 80%）。依模擬（10 輪），答對率 80% 的學生在「普通」難度下贏得第一的機率約為：對 1 位電腦 56%、2 位 42%、3 位 33%。實力越好越容易贏，但骰子與卡片仍有運氣成分，不會穩贏，也不會贏不了。

### 🏅 勝利證書

- **條件**：以「普通」或「困難」難度拿下**第一名**，而且你至少擲過 5 次骰子（避免開局馬上放榜拿證書）。在「簡單」難度贏了會提示改挑戰普通以上；沒拿到第一則顯示鼓勵的話與「再考一科」按鈕。
- **內容**：宣紙底、朱紅雙框與印章，寫有姓名（及班級、座號）、「范進命運棋　金榜題名」、聲望分數、答對題數、難度、日期（民國紀年），以及「認證者：永春高中 龎海珊 老師」。
- **下載 PNG**：按「⬇ 下載證書（PNG）」，檔名為 `范進命運棋證書_姓名.png`。
- **列印**：按「🖨 列印證書」，列印頁只會印出證書（A4 橫式，一頁）。
- **修改認證者**：打開 `index.html`，找到程式最上方標有 ★ 的這一行，改引號裡的文字即可：
  ```js
  const CERTIFIER = '永春高中 龎海珊 老師';
  ```
  （目前依委託內容照登「龎」字；若應為「龐」，改這一行就好。）

### 📱 用手機玩

- **直式、橫式都可以**（建議直式）。直式時：上方是精簡的考生狀態列（棋子、名字、聲望），中間是棋盤，下方固定「🎲 擲骰子」；題目與卡片會以**全螢幕**顯示，選項按鈕都夠大，方便手指點選。
- **棋盤自動放大**：手機上 2D 棋盤預設放大約 1.6 倍，可以上下左右滑動，並會**自動捲到正在走的棋子**（擲骰時先捲到中間看骰子）。左下角 🔍 可切換「放大／整面」。
- **自動模式在手機上預設用 2D**（省電、省流量、不發燙）；記憶體與處理器明顯夠力的手機才會先試 3D，跑不順仍會自動退回 2D。想看 3D 可按上方「3D」按鈕手動切換。
- **證書**：手機上按「⬇ 下載證書」會叫出系統分享選單（iPhone／Android 可選「儲存影像」）；不支援時改為直接下載。也可以按「🖼 開啟圖片」在新分頁打開，或**直接長按證書圖片**→「加入照片」。手機上不顯示「列印」按鈕。
- **音樂**：手機規定要點一下畫面才能出聲，所以背景音樂在第一次點畫面後才開始。切到別的 App、鎖螢幕或切換分頁時會自動暫停，回來後續播（若系統不允許自動續播，再點一下畫面即可）。
- **進度**：每一步都會自動存在手機瀏覽器裡；切出去再回來，或瀏覽器被系統關掉，重新打開按「繼續上局」即可（同一支手機、同一個瀏覽器才有效；無痕模式關閉後會清除）。
- **流量**：第一次開啟約需 2–3 MB（遊戲本體約 170 KB，加上 Tailwind、字型）；背景音樂另約 4.3 MB，只在開著音樂時才會串流下載，用行動網路可在 ⚙ 關掉音樂；3D 模組（約 0.7 MB）只在使用 3D 時才下載。建議先連 Wi-Fi 開一次。
- 已防止誤觸縮放（雙擊放大、雙指縮放整頁），並避開瀏海與底部 Home 條。

### 3D／2D 與裝置
- 「自動」模式：先嘗試 3D；如果裝置不支援 WebGL、3D 元件載入失敗，或開局約 2 秒內畫面低於 24 FPS，會自動改用 2D，並跳出提示。
- 3D 操作：拖曳旋轉、雙指（或滑鼠滾輪）縮放、雙擊回正；點格子可看該格說明。
- 支援電腦、iPad、Android 平板，橫放與直放皆可（建議橫放）。
- 遊戲進度會自動存在瀏覽器裡，關掉重開可以「繼續上局」（舊版分組存檔無法接續）。

## 二、部署到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `fanjin-game`），設為 **Public**。
2. 把本資料夾的檔案上傳到 repository 根目錄：
   - `index.html`（必要）
   - `bgm.mp3`（背景音樂，可省略）
   > 網頁上傳：repository 頁面 →「Add file」→「Upload files」→ 拖曳檔案 →「Commit changes」。
3. 進入 repository 的 **Settings → Pages**：
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**、資料夾選 **/(root)** → **Save**
4. 等 1–2 分鐘，網址會是：`https://你的帳號.github.io/fanjin-game/`

> 遊戲會從網路載入 Tailwind、字型、three.js（3D）與 SheetJS（Excel 匯入），所以上課的裝置需要能上網。
> 想在本機測試，請用簡易伺服器開啟（直接雙擊 html 也能玩，但部分瀏覽器會擋 3D 模組或音樂）：
> `python3 -m http.server 8000` → 瀏覽器打開 `http://localhost:8000/`

## 三、更換背景音樂

1. 準備一首音樂（建議 1–3 分鐘、可循環的古風或國樂配樂，MP3 格式，2–5 MB 以內較好載入）。
2. 檔名改成 **`bgm.mp3`**，覆蓋本資料夾的舊檔，再上傳到 GitHub 即可。
3. 遊戲中右上角 ♪ 可開關音樂，⚙ 可分別調整音樂與音效音量。
4. 瀏覽器規定要有一次點擊後才能出聲，所以音樂會在第一次點擊畫面後才開始播放。若找不到 `bgm.mp3`，遊戲照常進行，只是沒有背景音樂。

音效（骰子、答對、答錯、得分、翻卡）由程式即時合成，刻意做得短而輕（撥弦與木魚聲），可在設定中單獨關閉。

## 四、教師模式（題庫）

首頁或遊戲中的 ⚙ →「教師模式」：

- 新增、編輯、刪除題目（2–4 個選項；只填 A、B 兩個選項即成為是非題／二選一）。
- **匯出 JSON／匯入 JSON**：把題庫帶到其他裝置或分享給其他老師。
- **匯入 Excel／匯出 Excel（範本）**：建議先「匯出 Excel」當範本，修改後再匯入。
  欄位：`分類｜題目｜選項A｜選項B｜選項C｜選項D｜答案（A–D）｜解析`
- 匯入時可選擇「取代」或「附加」到現有題庫；「還原預設題庫」可回到內建 40 題。
- 題庫存在該瀏覽器的 localStorage，換裝置請用匯出／匯入。

JSON 格式範例（`a` 為正解的索引，從 0 起算；也接受 `"A"`～`"D"`）：

```json
[
  { "cat": "科舉制度", "q": "鄉試考中的人稱為什麼？", "o": ["秀才", "舉人", "貢士", "進士"], "a": 1, "e": "鄉試考中稱舉人，第一名稱解元。" }
]
```

內建題目分類：字音字形、詞義、文意理解、人物形象、寫作手法、科舉制度、作者與儒林外史、主旨。

## 五、檔案結構

```
index.html      遊戲本體（HTML + Tailwind CDN + 原生 JS；3D 版動態載入 three.js）
bgm.mp3         背景音樂（可自行替換）
README.md       本說明
```

程式內分為：資料（題庫、棋盤格、卡片）→ 音訊 → 2D 畫面 → 3D 畫面 → 遊戲流程 → 介面／教師模式。遊戲邏輯與畫面分離，3D 與 2D 共用同一份遊戲狀態。
